Adapted in Kotlin: sliding/rolling/spinning/airborne evolution, instantaneous
point cue strike and squirt, Alciatore frictional inelastic ball collisions,
Han 2005 cushion collisions. Original Python/NumPy implementation replaced
with Kotlin vectors. Android integration, table geometry, continuous collision
scheduling, rules, procedural artwork, environments and audio are new work.
This is a port of these physics models, not of Pooltool's Python GUI or every
optional resolver. Han is used for grounded balls; an impulse model handles
airborne cushion contacts. Pocket jaws and landing use bounded impulses.

Kiefl, E. (2024). Pooltool: A Python package for realistic billiards simulation.
Journal of Open Source Software, 9(101), 7301.
